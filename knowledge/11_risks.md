# Riscos

Curto prazo:

- baixa retenção
- pouca diferenciação
- inconsistência visual

Médio prazo:

- custos de IA
- custos de memória
- moderação

Longo prazo:

- concorrentes
- dependência de plataformas
- regulamentação
- fragmentação da personagem

Riscos de produto:

- apresentar interface visualmente pronta com conversa ruim
- expor funcoes falsas como se estivessem implementadas
- mostrar memoria, online, assinatura, login ou pagamento simulados ao usuario comum
- deixar elementos internos de beta, MVP ou debug vazarem para a interface publica
- focar primeiro em tecnologia
- adicionar dezenas de funcionalidades antes do núcleo funcionar
- trocar aparência frequentemente
- trocar personalidade frequentemente
- depender de algoritmo de rede social
- lançar experiência ruim ao público
