# Visão do Projeto

Luna é uma personagem virtual brasileira.

Objetivo principal:

Criar uma companheira virtual capaz de gerar apego emocional de longo prazo.

O produto principal não é o chatbot.

O produto principal é o relacionamento.

O chatbot é apenas o meio.

Mercado inicial:

Brasil.

Expansão futura:

Internacional.

Monetização:

- Assinatura mensal
- Recursos premium
- Futuras expansões de produto

Prioridade máxima:

Retenção.

Objetivo emocional máximo:

Fazer falta quando o usuário passa um tempo sem conversar com ela.

Objetivo final:

Criar uma personagem que o usuário reconheça imediatamente, lembre com carinho e queira reencontrar.

O sucesso não deve ser medido apenas por quantas pessoas acharam a Luna bonita.

O sucesso deve ser medido por quantas pessoas sentem falta dela.

Direção de longo prazo:

- Branding forte
- Comunidade
- Crescimento orgânico
- Expansão internacional futura
